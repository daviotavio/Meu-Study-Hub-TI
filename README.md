## Sobre este repositório

O **Study Hub** é, além de um trabalho de disciplina, a base estrutural do meu portfólio profissional. A proposta é documentar minha evolução ao longo do curso de forma padronizada e acessível, reunindo em um só lugar tudo o que aprendo e produzo.

Trabalho com dados e Business Intelligence, e escolhi Engenharia de Software para aprofundar minha formação técnica. Este repositório refletirá essa trajetória.

### Lógica da organização

| Pasta | O que guarda |
|---|---|
| **00_Apresentacao_Perfil** | Minha apresentação pessoal, trajetória e formas de contato |
| **01_Engenharia_de_Software** | Entregas e anotações de cada disciplina do curso |
| **02_Projetos_Dados_e_BI** | Projetos de Power BI, scripts e documentação da minha área de trabalho |
| **03_Certificacoes** | Certificados obtidos |

Cada disciplina segue o mesmo padrão: uma subpasta para **entregas** (trabalho avaliado) e outra para **anotações e resumos** (material de estudo). Isso mantém o portfólio previsível e fácil de navegar à medida que o curso avança.
