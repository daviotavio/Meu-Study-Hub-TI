# Portfólio — Davi Otávio

Site de portfólio pessoal publicado com **GitHub Pages**. Página estática (HTML, CSS e JavaScript puro) — sem dependências nem etapa de build.

## 📂 Estrutura

```
.
├── index.html          # Página principal
└── assets/
    ├── style.css       # Estilos
    └── main.js         # Contagem das métricas + ano do rodapé
```

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório no GitHub. Para o site ficar no endereço `https://SEU-USUARIO.github.io`, nomeie o repositório exatamente como **`SEU-USUARIO.github.io`**. (Qualquer outro nome também funciona — o endereço só muda para `https://SEU-USUARIO.github.io/nome-do-repo/`.)
2. Envie estes arquivos para a raiz do repositório (`index.html` na raiz, não dentro de subpasta).
3. No GitHub, vá em **Settings → Pages**.
4. Em **Source**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`. Salve.
5. Aguarde 1–2 minutos e acesse o endereço que o GitHub mostrar nessa mesma tela.

## ✏️ O que personalizar

- **Link do GitHub** em `index.html` (seção Contato) — hoje aponta para `https://github.com/`.
- Adicionar/remover projetos: duplique um bloco `<article class="proj-card">`.
- Cores: variáveis no topo de `assets/style.css` (`:root`).
